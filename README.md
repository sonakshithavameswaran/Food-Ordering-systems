Online Food Ordering System

A simple Java-based console application that simulates the basic process of ordering food online.

About the Project

This project allows a customer to enter their details, explore the available food menu, select food items, create an order, view the order summary, and calculate the total bill.

The main purpose of this project is to apply Core Java and Object-Oriented Programming concepts in a practical application.

Features
Customer details management
Food menu display
Food item selection
Add items to order
View order summary
Automatic bill calculation
Order confirmation
Simple menu-driven interface
